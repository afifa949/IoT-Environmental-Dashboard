# IoT-Environmental-Dashboard
IoT Environmental Dashboard by 2nd-year CSE (DS) students of SR University. Uses a DHT11 sensor to collect real-time temperature and humidity data, sends it to AWS IoT Core, and displays readings on a cloud dashboard and OLED.
