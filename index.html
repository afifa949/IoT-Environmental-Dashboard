About AtmosSense

AtmosSense — Sense the Air System

About the Product

AtmosSense is an environmental monitoring system designed to measure temperature and humidity in real time. The system uses an ESP32 microcontroller connected to a DHT11 sensor. Sensor readings are transmitted through Wi-Fi using MQTT to AWS IoT Core. Cloud services process, store and monitor the collected information while the web dashboard provides an easy-to-understand visualization of environmental conditions.
